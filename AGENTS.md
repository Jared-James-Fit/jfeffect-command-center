- Logging Level points are awarded only by DB triggers into `athlete_xp_events` with unique per-record/day/week `source_key`s — why: idempotent, no client-side farming, history backfillable.
- Achievement "seen" state lives in `athlete_achievement_views` (server-side), never localStorage — why: reveals must not replay across devices.
- Member-to-member chats (`chat_groups.kind = 'direct'`) are private to the two members: staff RLS, group lists and "View as client" must never include them, and request state (accept/delete/block/report) changes only through `chat_direct_respond` / `community_message_author` — why: requests must stay silent (the sender can't tell a decline from unread) and reports are the coach's only window in.
